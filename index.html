Tentang RynerHUB

RynerHUB adalah script hub yang memakai sistem key. Key gratis dan berlaku 2 hari sejak dibuat. Satu perangkat bisa punya sampai 3 key aktif.

  1. Tekan Next lalu selesaikan safelink pada tiap tahap (total 4 tahap).
  2. Setelah semua checkpoint selesai, tekan Claim Key.
  3. Salin key dengan tombol Copy. Sisa waktu key tampil di sampingnya.
  4. Masukkan key ke RynerHUB saat diminta, lalu jalankan script. Kalau key sudah expired, buat key baru.
